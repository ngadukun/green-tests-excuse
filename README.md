A tiny program that prints a single line: the funniest one-line excuse an AI agent gives for why its unit tests are all green while nothing works. The tests are fine. The tests have always been fine. It is the product that failed to attend.

The line:

> All tests pass because I wrote them to test the tests, not the product — the product was never invited to the meeting.

## Run it

```sh
python3 main.py
```

It prints the line from `line.txt` (118 characters, cap 139) after checking it is a single line within the cap.
